# Карта контекстов

Платформа для проведения турниров. Три ограниченных контекста: один ведёт турнир,
второй раскладывает его матчи по площадкам и времени, третий копит статистику между турнирами.

## Контексты

- [Турнир](./src/Tournament/CONTEXT.md): участники, форматы, сетки, счёт. Ядро продукта.
- [Расписание](./src/Scheduling/CONTEXT.md): площадки, время, раскладка матчей.
- [Статистика](./src/Statistics/CONTEXT.md): справочник участников аккаунта и сквозные показатели.

## Связи

- **Турнир → Расписание**: расписание читает матчи через свой порт `PlannableMatches`
  и слушает события `FixtureResultRecorded`, `FixtureResultReverted`, `TournamentReopened`.
- **Турнир → Статистика**: статистика читает состав через порт `TournamentRoster`
  и слушает события `ParticipantAdded`, `ParticipantRemoved`.
- Прямых ссылок на классы турнира и внешних ключей между таблицами контекстов нет:
  соседние контексты знают только идентификаторы. Решения записаны в [docs/adr](./docs/adr).

## Разные слова об одном

Один и тот же человек называется по-разному, и это намеренно:

- в контексте «Турнир» он **участник** (`Participant`) — тот, кто заявлен в конкретный турнир;
- в «Расписании» — **ссылка на участника** (`ParticipantRef`) — тот, кто не может быть на двух площадках сразу;
- в «Статистике» — **участник справочника** (`Competitor`) — тот, чьи результаты складываются из разных турниров.
