# Метки триажа

Скиллы оперируют пятью каноническими ролями триажа. Этот файл сопоставляет роли реальным строкам
меток в трекере задач репозитория. У нас трекер — локальный markdown, значение пишется в строку `Status:` тикета.

| Метка в mattpocock/skills | Метка у нас        | Смысл                                              |
| ------------------------- | ------------------ | -------------------------------------------------- |
| `needs-triage`            | `needs-triage`     | Мейнтейнеру нужно оценить задачу                   |
| `needs-info`              | `needs-info`       | Ждём от автора дополнительную информацию           |
| `ready-for-agent`         | `ready-for-agent`  | Полностью описана, готова для автономного агента   |
| `ready-for-human`         | `ready-for-human`  | Требует реализации человеком                       |
| `wontfix`                 | `wontfix`          | Делать не будем                                    |

Когда скилл упоминает роль (например, «поставить метку готовности для агента»), использовать
соответствующую строку из таблицы.

Правая колонка правится под тот словарь, который реально используется.
