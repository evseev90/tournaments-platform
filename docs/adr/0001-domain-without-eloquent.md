# Доменный код не использует Eloquent

Доменные классы в `src/` — обычный PHP без наследования от моделей Laravel, а репозитории собирают
агрегаты вручную через Query Builder. Eloquent — Active Record: модель знает о базе, и агрегат,
унаследованный от неё, перестаёт быть местом, где живут правила турнира.

Цена решения честная: кода примерно в полтора раза больше, а часть удобств фреймворка недоступна.
Взамен домен тестируется без базы и без загрузки Laravel, и статический анализ на девятом уровне
проверяет его целиком. Для учебной цели проекта — пощупать DDD — это и есть главный смысл.

Читать и писать по-разному: команды поднимают агрегаты через репозитории, а страницы получают данные
отдельными запросами, которые сразу отдают DTO.
