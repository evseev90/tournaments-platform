# Участники сводятся по имени, статистика считается на лету

Сквозная статистика связывает участников разных турниров по нормализованному имени внутри аккаунта,
а не по явно выбранному профилю из справочника. Показатели при этом считаются запросом по матчам,
без отдельной проекции.

Выбор про имена — обмен точности на скорость ввода. Организатор вставляет список из мессенджера
за пару секунд, и требовать от него выбирать каждого из справочника значит сломать главный сценарий
продукта. Цена: опечатка создаёт второго человека, а два разных однофамильца сливаются в одного.
Обратить решение дорого, потому что связи уже записаны в данных, поэтому объединение и переименование
участников справочника придётся делать отдельной функцией.

Отказ от проекции — обмен производительности на простоту. У клуба тысячи матчей, а не миллионы,
поэтому подсчёт по запросу занимает миллисекунды. Проекция, обновляемая по событиям, добавила бы
второй источник правды и способы с ним разойтись. Если объёмы вырастут, проекция добавляется
поверх тех же событий, ничего не ломая.
